# ت.ش للمنتجات | T.S.P

متجر عربي ثابت لبيع منتجات رقمية (كتب وحزم) مع سلة وعملات ومراجعات ودفع بإثبات تحويل، مبني بـ HTML وJavaScript وPHP وMySQL.

## 1 ما هو المشروع

عنوان الصفحة: «ت.ش للمنتجات | T.S.P». الميتا: متجر متخصص ببيع المنتجات الرقمية التقنية كالكتب والبرمجيات والملفات وغيرها، والمؤلف تلر الشهراني. الشعار في البانر: «تعلم، برمج، احمِ، دافع، مع تلر الشهراني!». الصفحة تعلن «عدد المنتجات : 5».

## 2 لماذا بُني

النص يعد بتعليم الأمن السيبراني والبرمجة وصناعة المحتوى والتجارة والتسويق، مع دعم وأسعار وتخفيضات. غير موثق كيان تجاري خارج نص الصفحة.

## 3 من يستخدمه

| الشخص | ما يفعله |
| --- | --- |
| زائر | يتصفح ويغيّر العملة ويضيف للسلة |
| مشتري | ينتقل لصفحة الدفع ويرفق صورة التحويل |
| كاتب مراجعة | يرسل اسماً ونصاً وتقييماً وصورة رمزية |

لا لوحة مدير في الملفات.

## 4 الميزات

- أقسام: رئيسية، منتجات، مراجعات، أسئلة، دعم، سياسات (`politics/index.html`).
- تصنيفات العرض: الكل، الأحدث، الأكثر مبيعاً، التخفيضات، الأكثر سعراً، الأدنى سعراً، كتب، حزم.
- قائمة عملات عربية وعالمية. التحويل من Open Exchange Rates.
- سلة في المتصفح ثم التوجه إلى `payment/`.
- مراجعات عبر `handling.php` مع رفع صورة إلى `uploads/`.
- دفع في `payment/handling.php` لطرق تشمل سداد أو عملات رقمية كما في تعليق الملف، مع مرفق تحويل.
- صفحة شكر `payment/thx/`.
- Favicon يشير إلى `assets/images/‏‏My Logo Without Bg.icon`.
- Font Awesome 6.2.0 من CDN. خط IBM Plex Sans Arabic.

## 5 سير العمل

```
index.html
  |-- تصفية وتصنيف محلي
  |-- جلب أسعار الصرف (مفتاح في script.js)
  |-- سلة -> payment/
  |-- مراجعات GET/POST handling.php -> MySQL reviews
  +-- بريد EmailJS من script.js (معرّفات داخل الملف)

payment/index.html
  POST payment/handling.php -> جدول payments + ملف في uploads/
  ثم payment/thx/
```

عناوين المنتجات الخمسة في `index.html`:

| المنتج | السعر بالريال الظاهر في السمات |
| --- | --- |
| كتاب دليلك الشامل لأقوى الشهادات الاحترافية التقنية والتصميمية | غير ظاهر كـ data-price-sar في نفس موضع بقية البطاقات |

سمات عملات أخرى كثيرة موجودة وقيمها فارغة في المقاطع المفحوصة، والتحويل الآلي يعتمد على سعر الصرف لا على تلك السمات الفارغة.

ملفات PDF تحت `assets/products/` منها مجلد `free`. أسماء الملفات بالعربية في المجلد.

## 7 رحلة المستخدم

1. يفتح المتجر ويرى البانر وعدد المنتجات.
2. يصفّي التصنيف فتظهر البطاقات المطابقة لـ `data-category`.
3. يبدّل العملة فتُحدَّث الأسعار من أسعار الصرف إن نجح الطلب.
4. يضيف إلى السلة أو يشتري. `redirectToPayment` ينقل السعر والعملة ومعرّف المنتج والاسم.
5. في الدفع يكتب الاسم والبريد وطريقة الدفع والمبلغ ويرفق ملفاً.
6. عند النجاح يصل إلى صفحة الشكر.
7. يستطيع إرسال مراجعة مع صورة jpg أو jpeg أو png أو webp.

## 18 الواجهة الأمامية

اتجاه RTL. قائمة مع قوائم فرعية للمنتجات والسياسات. بطاقات منتج ومعاينة. سلة. نموذج مراجعة. صفحة دفع منفصلة ثم شكر. `.htaccess` يرسل `Cache-Control: no-store` عند توفر `mod_headers`.

## 19 الخادم

كلا ملفي PHP يتصلان بـ `localhost` / `root` / كلمة فارغة / `My_Digital_Store`.

`handling.php` للجذر: GET يعيد المراجعات، POST يدرج مراجعة.

`payment/handling.php`: POST يتحقق من الاسم والبريد والطريقة والمرفق ثم يدرج في `payments`.

## 20 تدفق الطلب

مراجعة: `fetch('handling.php')` ثم POST بـ `FormData` للحقول name وreview وrating وملف avatar.

دفع: نموذج إلى `payment/handling.php` بالحقول name وemail وpayment_method وamount وملف transfer. الامتدادات المسموحة: jpeg وjpg وpng وwebp وpdf. الملف يُحفظ في `uploads/` باسم `{وقت}_{اسم أصلي}`.

فشل اتصال المراجعات يستخدم `die` مع JSON. فشل اتصال الدفع يعيد JSON ثم `exit`.

## 24 الأمان

- سر واجهة الصرف ومفاتيح EmailJS داخل JavaScript.
- مستخدم القاعدة root وكلمة فارغة.
- رفع الملفات يعتمد على الامتداد والاسم الأصلي في الدفع (`basename` مع الطابع الزمني).
- صور المراجعات تُقبل بالامتداد فقط.
- مخرجات المراجعات تمر على `htmlspecialchars` عند القراءة.
- لا CSRF.
- مجلد `uploads` يحوي صوراً وأسماء أشخاص وملف صوت. هذه محتويات مستخدمين وليست للتوثيق.

## 30 التثبيت

1. Apache وPHP وMySQL.
2. أنشئ قاعدة `My_Digital_Store` وجدولي `reviews` و`payments` بالأعمدة المستخدمة.
3. ضع المشروع تحت جذر الخادم حتى تعمل مسارات `handling.php` و`uploads`.
4. افتح `index.html` عبر HTTP وليس كملف محلي إذا لزم `fetch`.

## 31 دليل المطور

- عدد «5» مكتوب نصاً في HTML. أضف بطاقة وعدّل الرقم معاً.
- أسعار SAR في سمات `data-price-sar`.
- مسار رفع الدفع: `realpath` لمجلد `uploads` في جذر المشروع من `payment/handling.php` (`../uploads`).
